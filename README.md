# 🌸 FNP Sales & Operations Analytics Dashboard

An interactive Excel dashboard built to analyze and visualize retail sales performance for **Ferns N Petals (FNP)**, tracking 1,000 orders and ₹35.2L+ in total revenue[cite: 1].

## 📌 Project Overview
This project transforms raw gift retail data into actionable business intelligence using advanced Excel features. It evaluates seasonal sales peaks, product category performance, hourly purchasing trends, and delivery logistics.

---

## 📊 Key Insights
* **Top Revenue Drivers:** **Anniversary** and **Raksha Bandhan** lead seasonal sales by occasion, while the **"Colors"** category dominates overall product category revenue[cite: 1].
* **Peak Performance Months:** Sales experience massive spikes during **February** and **August**[cite: 1].
* **Customer Metrics:** Achieved an average customer spend of **₹3,520.98** across 1,000 total orders with an average delivery time of 5.53[cite: 1].
* **Top Products:** High-demand items like the **Magnam Set** and **Quia Gift** rank among the top-performing products[cite: 1].

---

## 🎛️ Dashboard Features
* **Interactive Slicers:** Dynamic filters for Order Date, Delivery Date, and specific Occasions (Anniversary, Birthday, Diwali, etc.)
* **Visual Breakdown:** Multi-dimensional layout including KPI summary cards, donut charts for gender and day-of-week splits, and bar/line charts for hourly and city-level performance.
